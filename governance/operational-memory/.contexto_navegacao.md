## Ordem de Leitura para Novo Agente (RLM)

```
 ① contexto_rlm.md                        ← "Onde estou?" (30 segundos)
    │
 ② diario_de_bordo.md                     ← "O que já fizemos?" (última sessão)
    │
 ③ governance/standards/manual_do_ecossistema.md ← "Quais são as regras?" (sob demanda)
    │
 ④ Este arquivo                           ← "Onde encontro X?" (referência rápida)
    │
 ⑤ governance/projects/PRJ-XX_*/          ← Scaffold vazio para docs do próximo projeto
```

> **Regra:** Não leia tudo de uma vez. Siga a hierarquia RLM: comece pelo nível mais compacto e aprofunde sob demanda.
